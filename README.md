# Codsoft_Task5_Contact_book

## 📌 Project Overview

The Contact Book is a Python-based GUI application designed to
manage contact information.

The application allows users to add, view, search, update, and delete
contacts.

Each contact can contain:

- Name
- Phone number
- Email address
- Address

The application uses JSON file storage so that contacts remain
available even after the program is closed.

This project was developed as part of a Python Programming Internship.

---

## 🎯 Objective

The objective of this project is to create a simple contact management
system while gaining practical experience with GUI programming,
CRUD operations, file handling, JSON data storage, and
Object-Oriented Programming.

---

## ✨ Features

### ➕ Add Contact

Users can add a new contact by entering:

- Name
- Phone number
- Email
- Address

### 👁️ View Contacts

All saved contacts are displayed in a table.

### 🔎 Search Contact

Users can search contacts using:

- Name
- Phone number

### ✏️ Update Contact

Existing contact information can be modified.

### 🗑️ Delete Contact

Users can delete a selected contact after confirmation.

### 💾 Data Persistence

Contacts are stored in a JSON file so that data is preserved between
program executions.

### 🧹 Clear Fields

The input fields can be cleared using the Clear button.
